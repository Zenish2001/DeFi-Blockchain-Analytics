# SimpleAMM

A Uniswap-V2-style constant-product automated market maker for a single token pair, built in Solidity. Supports three actions — deposit (add liquidity), redeem (remove liquidity), and swap (trade one token for the other) — with a 0.30% swap fee.

Like the Uniswap V2 Pair, this contract is itself the liquidity ("LP") token: it inherits ERC20, so LP units are real, transferable tokens minted on deposit and burned on redeem. The pool involves three token types: atomic tokenA, atomic tokenB, and the minted LP token.

## Structure

```
simple-amm/
├── contracts/
│   ├── SimpleAMM.sol      # the contract under test (also the ERC20 LP token)
│   └── MockERC20.sol      # mintable ERC20 used only by tests
├── test/
│   └── SimpleAMM.test.js  # full suite (100% line + branch coverage)
├── hardhat.config.js
└── package.json
```

## Setup & Run

```bash
cd simple-amm
npm install          # installs Hardhat, OpenZeppelin, solidity-coverage
npx hardhat compile
npx hardhat test
```

### Generate the coverage report

```bash
npx hardhat coverage
```

This produces `coverage/index.html` (open in a browser). `solidity-coverage` instruments only the `contracts/` folder, so inherited OpenZeppelin code doesn't count against the result — `SimpleAMM.sol` and `MockERC20.sol` both report 100% line and branch coverage. A text summary also prints to the terminal.

Note: the coverage tool runs the tests itself against an instrumented build, so the HTML report is generated by running `npx hardhat coverage`, not by opening a pre-built file.

## How the Swap Price Works

Output for an exact input, with the fee taken on the input (identical to Uniswap V2):

```
amountOut = (amountIn * 997 * reserveOut) / (reserveIn * 1000 + amountIn * 997)
```

To model a fee-free AMM instead, set `FEE_NUM = FEE_DEN = 1000` in `SimpleAMM.sol` — this reduces the formula to `amountOut = amountIn * reserveOut / (reserveIn + amountIn)`.

## What's Implemented

- Complete Solidity contract (`SimpleAMM.sol`)
- `swap`, `deposit`, and `redeem` functions
- Constant-product (x·y=k) pricing with a 0.30% fee, matching Uniswap V2's formula
- A real, transferable ERC20 liquidity token (minted and burned automatically)
- A comprehensive test suite with 100% line and branch coverage
- An HTML coverage report, generated via `npx hardhat coverage`

## Deliberate Simplifications vs. Production Uniswap V2

- No `MINIMUM_LIQUIDITY` lock on the first deposit (the first-depositor inflation guard is omitted for clarity)
- Reserves are tracked explicitly, not synced from `balanceOf`, so tokens sent directly to the contract are ignored by the pricing math

## Test Coverage

Every branch in `SimpleAMM.sol` is exercised, including constructor validation, deposit/redeem edge cases (zero amounts, imbalanced ratios, insufficient balance), both swap directions, slippage protection (`minAmountOut`), and the integer square root helper used for the first liquidity mint.

## Extending This Contract

This contract is extended with a live web3 UI in [`../amm-web-ui/`](../amm-web-ui/) — pool selection, deposit/redeem/swap actions, and on-chain analytics (a reserves curve chart and a swap execution-price distribution built from historical `Swap` events).
