How it works

  1. Sync. ingest.py calls my Bitcoin Core node over RPC (getblock, verbosity 2) and writes blocks, transactions, inputs and outputs into SQLite.
  2. Prompt. Your question and the database schema go to Gemini 2.5 Flash, which must answer with SQL only, or CANNOT_ANSWER if the question isn't about this data.
  3. Check. Only a single SELECT is allowed, on a read-only connection, with a time and row limit.
  4. Show. The SQL, the rows, a chart when it fits, and timings come back to this page.
